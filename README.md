# Interfacing-DHT11-Sensor-with-STM32F411VE-STM32CubeIDE
Interfacing DHT11 temperature and humidity sensor with STM32F411VE using STM32CubeIDE. Reads sensor data using a single-wire protocol and displays values via UART on Tera Term. Activates an LED and buzzer when temperature exceeds a defined threshold. Implements microsecond delays and GPIO mode switching.
